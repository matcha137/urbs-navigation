`?demo=1` で位置情報の許可ダイアログを飛ばし、天気を「18°・小雨、14時には上がる」に固定する。

### 実測値（`?demo=1` = 雨18°、清澄白河駅起点）

| しかた | 30分 | 60分 | 90分 |
|---|---|---|---|
| のんびり歩く | 2箇所 455m | 3箇所 897m | 4箇所 1,531m |
| 水辺を歩く | 1箇所 311m | 3箇所 1,291m | 4箇所 1,839m |
| しっかり歩く | 2箇所 615m | 3箇所 911m | 4箇所 1,640m |
| 屋内で休む | 1箇所 283m | 2箇所 771m | 3箇所 1,500m |

**見出しと理由文は LLM が毎回書くので、文言は実行ごとに変わる。**
数字（距離・箇所数・トイレまでの距離）はルールベースなので固定。
リハーサルで見た文がそのまま本番で出るとは限らない前提で話すこと。

### 触ってはいけないところ

- **出発地点は5区24駅しかない。** 23区すべてのカタログを当たって、
  公園データに緯度経度が入っている区がこれだけだったため（[datasets.md](datasets.md)）。
  渋谷・池袋・東京は最寄りの場所が 2km 以上先で、30分圏内は 0件になる。
- **区によって選べるしかたが違う。** 台東・目黒・新宿には屋内施設のデータが無く、
  「屋内で休む」が灰色になる。**これは不具合ではなく、デモで見せる要素**（手順7）。
  灰色のカードには理由が書いてあるので、それを読み上げればいい。
- **「水辺を歩く」は名前からの判定。** 画面にもその注記が出る。
  「川に面していると保証しているのか」と聞かれたら、していないと答える。
  江東区と杉並区の一部でしか成立せず、他の区では選べない。

## 締め（1:25–1:30）

> 「江東区の公衆トイレデータは、車椅子対応の有無が全192件に入っています。
> でも公園データの側には段差もベンチも無い。
> 足りない属性を、隣接するデータから距離で補いました。
> 同じことを5区・1,411件でやっています。
> そして**足りないものは足りないと画面に書いています**。」

## 事故対策（当日ここを確認する）

| 起きうること | 対策 | 担当タスク |
|---|---|---|
| 位置情報が許可されない / 出ない | 4秒で打ち切り、清澄白河駅を選択状態にする。**座標ではなく駅を起点にする**ので、区外にいても0件にならない | T-51, T-91 |
| 天気APIが落ちる | `degraded.weather=true` で天気補正なしのプランを返す。画面に「天気を取得できませんでした」と出る | T-34, T-58 |
| LLMが遅い・落ちる | 6秒でタイムアウトし、ルールベースの定型文に差し替え。画面に「定型の文で表示しています」と出る | T-73 |
| 自然文検索が落ちる | ことばの一致で返す。画面に注記が出る（質疑で使うときだけ関係する） | T-39 |
| 会場のWi-Fiが遅い | 直前に全エンドポイントを1回ずつ叩いてウォームしておく。天気は30分、理由文は24時間キャッシュされる | T-90 |
| 画面共有で文字が小さい | スマホ実機ではなくブラウザのモバイル幅（375px）で見せる | T-93 |
| Google Fonts が届かない | 端末の日本語フォントに落ちるだけ。レイアウトは崩れない | — |

## 聞かれたら正直に答えること

審査員に「ベンチの数はどこから？」と聞かれる可能性がある。**推定であることを隠さない。**

| 質問 | 答え |
|---|---|
| ベンチや座れる場所は？ | ベンチ数のオープンデータは存在しません。公園の面積から推定していて、画面でも「〜ありそう」と推定の語尾にしています |
| 段差なしはどう判定した？ | 公共施設は区の登録値（スロープ・エレベータ欄）です。公園には段差データが無いので「不明」として扱い、「段差なし」とは表示していません |
| 手すりは？ | データが無いので機能から外しました |
| なぜこの5区だけ？ | 23区すべてのカタログを取って CSV を実際に落として確かめました。公園データは都の推奨フォーマットなので列は23区すべてに在りますが、**緯度経度に値を入れている区がこれだけ**でした。墨田・葛飾・練馬などは公園CSVの座標が全行空欄です |
| 区を増やすには？ | 座標が入っていない区は住所からのジオコーディングが要ります。推定した座標で「トイレまで62m」と言うことになるので、今回は入れていません |
| 水辺かどうかはどう判定した？ | 場所の名前です。「水辺」の実データは乗船場11件しか無く、歩く場所として使えませんでした。名前に川・堀・親水などが残っている場所を拾っていて、画面にもそう書いています |
| カフェや景色で選べないのは？ | 店舗のデータセットを取得しておらず、409件の説明文にも景観の記述がありません。出せないものはボタンにしませんでした |
